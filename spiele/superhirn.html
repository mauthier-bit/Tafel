So geht Superhirn

Einer legt einen geheimen Code aus farbigen Steinen. Der andere rät – und bekommt nach jedem Versuch eine Rückmeldung aus kleinen Stiften:

  • schwarz: ein Stein hat die richtige Farbe an der richtigen Stelle.
  • weiß: die Farbe kommt im Code vor, steht aber woanders.

Die Stifte verraten nicht, welcher Stein gemeint ist – nur wie viele. Jeder Stein zählt höchstens einmal, und schwarz geht vor weiß.

Wer den Code innerhalb der vereinbarten Versuche trifft, gewinnt. Die Kunst ist, jeden Versuch so zu wählen, dass er möglichst viel ausschließt – nicht einfach zu probieren.
